# Feature 093: Hourly Agreements with Payer != Client

*(Note: This feature officially absorbs and obsoletes Feature 051 (Hourly Reporting & Payment Request Creation).)*

**Status**: Backlog

Currently, hourly agreements assume the client is the payer. This feature will introduce the ability to explicitly decouple the Payer from the Client on hourly agreements, mirroring the functionality we have for standard fixed agreements.
