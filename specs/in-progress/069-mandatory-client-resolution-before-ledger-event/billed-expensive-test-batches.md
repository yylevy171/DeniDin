# Feature 069 — Billed/Expensive Test Batches

Generated 2026-09-05, on `feature/069-mandatory-client-resolution-before-ledger-event`,
covering every `billed`/`expensive`-marked test in `apps/denidin-app` (184 tests),
each assigned to exactly one of the 4 batches below (priority order: Batch 1 >
Batch 2 > Batch 3 > Batch 4 — a test that qualifies for more than one lands in
the earliest-listed batch). `apps/morning-mcp-app`'s own 3 billed tests are
excluded — all 3 already run+passed 2026-09-05, before this file existed.

## Batch definitions

- **Batch 1** — This feature's own tests (Feature 069's Phase 11 acceptance suite).
- **Batch 2** — The existing `@pytest.mark.sanity` subset (cross-app, high-signal).
- **Batch 3** — Pre-069 tests **directly impacted** by Feature 069's two real
  changes on this branch: (a) the mandatory client-resolution-before-capture
  mechanism replacing the old direct-capture path, and (b) the 2026-09-04
  JSON-only Morning MCP contract change (every Morning tool now returns JSON,
  not Hebrew prose) — any test that exercises a Morning MCP tool through a real
  OpenAI call, or exercises the old ledger-capture mechanism these tests
  predate, is impacted.
- **Batch 4** — Everything else (unrelated features: reminders, group etiquette,
  memory, plain connectivity, version query, generic media extraction, image
  classification, session transfer).
