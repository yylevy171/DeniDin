# Default personality

No named personality matches this directory. This should never happen — every
active window is expected to be running from the original/root clone or one of
the dedicated `teammate1`–`teammate5` clones, each with its own dedicated
personality file.

If you are reading this, stop and tell the user immediately: the current
working directory does not match any known personality (`root`/`teammate1`–
`teammate5`), which means the setup is misconfigured or a window is pointed at
the wrong folder (e.g. a stray/incorrectly-named clone, or a clone added
without a matching personality file yet).
Do not silently proceed as if this were normal.
